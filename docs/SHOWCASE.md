# Showcase: Puma / Wildbound for sidhulyalkar.com Game Network

Target placement: **https://sidhulyalkar.com/arcade** (Game Network), alongside Stretchicorn, uniRico, and Sylvaria.

## Positioning (what makes this unique)

Most portfolio platformers show jumps and coins. **Puma: Wildbound** is a **simulation-first predator fantasy**:

- **Headless 120 Hz core** with a large regression suite — movement, combat, and natural systems are designed to be *provably* consistent, not only “feel ok in the editor.”
- **Movement and combat share a language** — pounce becomes strike, stomp rebounds into glide, wall kick opens air-control, moonblooms answer claws with light and timed vines.
- **Natural systems as verbs** — wind ribbons, scent marks, updraft/wide-dazzle/vine blooms, limited bark climb — optional depth without gating the main trail.
- **Quiet narrative** — memories and wild places, not cutscene walls. Discovery opens golden return paths.

Tone for the site: precise, nocturnal, alive — aligned with the Neural Net visual language (monospace labels, dark ground, cyan/amber accents) but **warm amber fur + pale landing edges** so the cat reads instantly.

A Unity 2D exploration platformer about a puma hunting under the moon. Coil into a pounce, claw a moonbloom into a bridge of light, climb bark with a limited stamina budget, and follow scent to wild places that remember you.

**Blurb (long):**  
Three authored regions — Amber Canopy, Lantern Grotto, Sky Garden — teach a shared movement-combat language: charged pounce, wall kick, mantle, soft tail-glide, and claw-climb on living bark. Natural systems (wind, scent, bloom variants) create optional routes and moments without blocking the main trail. Built simulation-first at 120 Hz with executable regressions so feel stays durable as the world grows.

**Status line:** Unity playable · WebGL target · open source on GitHub

## Uniqueness bullets for the card / detail page

1. **Predator rhythm** — charge, release, strike, recover; hunting creates routes.
2. **Living terrain** — blooms, vines, bark, and wind respond to the same claws you fight with.
3. **Optional mastery** — wild places, waystone trials, and scenic lines never required for the exit.
4. **Engineering depth** — rectangular solver, sub-step CCD invariants, continuous projectile sweeps, large EditMode suite.
5. **Expandable world plan** — Cinder Ravine, Frostglass Ridge, and more designed as verb-driven biomes (see WORLD_EXPANSION.md).
